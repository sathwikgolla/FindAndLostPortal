# FindAndLost (Frontend)

Premium, modern **Lost & Found** UI for **FindAndLost** built with:

- Next.js (Pages Router) + React + TypeScript
- Tailwind CSS
- Framer Motion
- Lucide Icons
- `next-themes` (dark mode)

## Run

```bash
npm install
npm run dev
```

## Routes

- `/` Landing
- `/auth` Login / Register
- `/dashboard` Dashboard
- `/report-lost` Report Lost Item
- `/report-found` Report Found Item
- `/search` Search & Browse Items
- `/items/[id]` Item Details
- `/my-reports` My Reports
- `/profile` Profile
- `/admin` Admin Dashboard
